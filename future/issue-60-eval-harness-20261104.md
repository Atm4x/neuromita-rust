# Issue 60: offline A/B harness

Модуль `src/audio/eval.rs` оценивает любой `VadScoreProvider` на локальных
фикстурах. Ничего не скачивает и не подбирает пороги: порог передаёт вызывающий.

## Манифест

```json
{
  "fixtures": [
    {
      "id": "fleurs-ru-0001",
      "category": "ru",
      "wav": "fleurs-ru-0001.wav",
      "role": "calibration",
      "speech": [{ "start_sample": 12000, "end_sample": 84000 }]
    }
  ]
}
```

- `role`: `calibration` или `heldout`. Held-out прогоняется только после
  фиксации порога.
- `speech` — интервалы в целых сэмплах. Транскрипт не считается разметкой;
  пустой массив означает шум без речи.
- WAV: RIFF, PCM16, моно, 16 кГц, не длиннее 30 секунд. stereo, другой rate и
  битые чанки отклоняются до скоринга.

## Метрики

Скор считается окнами провайдера (256 или 512), метка — по середине окна:
precision, recall, F1, длительность ложной речи в секундах и ошибка границ
(onset/offset в мс относительно первой аннотации). При отсутствии аннотаций
границы не считаются, но ложные срабатывания остаются.

## Проверки

- `manifest_rejects_duplicate_ids_and_unordered_intervals`
- `wav_parser_rejects_stereo_and_short_files`
- `perfect_provider_reaches_f1_one_and_silent_provider_misses_everything` —
  сквозной прогон с временными файлами: идеальный провайдер даёт F1 = 1 и ошибку
  границ 0 мс, «молчащий» — recall 0 и 4 пропущенных кадра.

`cargo test --lib audio::` — 27 passed, 0 failed; clippy и fmt чистые.

## Чего нет

- Сам корпус не включён: FLEURS/ESC-10 требуют скачивания, а разметка границ —
  ручной работы. Манифест для них появится после этого.
- Нет калибровки порога и агрегации по категориям: это следующий шаг, когда
  будут реальные файлы.
- Метрики на записях ещё не получены, поэтому о качестве VAD ничего не заявляется.
