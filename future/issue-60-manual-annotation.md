# Ручная разметка VAD

Для готовой страницы запустите `python tools/build_vad_annotator.py` и откройте
`.cache/vad-annotator-ready.html` в современном браузере. Все 18 WAV, manifest и
транскрипции уже включены: можно сразу выбирать клип и размечать. Сервер и сеть
не нужны. Генератор использует только стандартную библиотеку Python; готовая
страница работает без Python. Исходные файлы не перезаписываются.

1. Послушайте запись. Голубая область — редактируемые границы речи, жёлтый пунктир
   под волной — неизменная исходная подсказка. Текст помогает понять запись;
   подтверждаются именно границы голоса.
2. Потяните левую или правую голубую ручку мышкой. Чтобы добавить отдельную фразу,
   протяните по свободному месту волны или нажмите «Выделить речь» и протяните
   нужный участок. Пересечения запрещены; край не перескочит через соседнюю фразу.
3. «Мой участок» проигрывает выделенную фразу, «Подсказка» — ближайший исходный
   интервал, «Вся запись» — весь клип. «Стоп» останавливает воспроизведение.
   Предпрослушивание использует длительность AudioBufferSource, поэтому слышен
   выбранный край, без дополнительного хвоста таймера HTML audio.
4. При необходимости приблизьте волну кнопкой «Масштаб» и перемещайте окно
   ползунком под волной. «Вся волна» возвращает исходный масштаб. Щелчок по волне
   перемещает позицию проигрывания. Отдельный участок выбирается щелчком по нему.
5. «Отменить правку» возвращает последнее состояние текущей записи (до 40 шагов).
   «Вернуть подсказку» возвращает исходные интервалы и требует нового подтверждения.
   Числа в сэмплах спрятаны в дополнительных настройках; без них можно разметить
   весь корпус. Ручки также доступны с клавиатуры: Tab, затем стрелки по 10 мс;
   Shift + стрелка — 100 мс.
6. После проверки всей записи нажмите «Границы верны → дальше». Если человеческого
   голоса вообще нет, нажмите «В записи нет речи → дальше» — это явное подтверждение
   отсутствия речи с очисткой предложенных интервалов. Страница перейдёт к следующей
   записи, а проверенная получит галочку. Стрелками можно вернуться к предыдущей.
7. Нажмите «Сохранить результат в JSON». Сохранится `manifest-manual.json` со всеми
   клипами и статусами. Экспортируйте и при перерыве в работе. Перед экспортом
   повторно проверяются WAV и интервалы; исходные файлы не перезаписываются.

При доступном localStorage изменения автоматически сохраняются и восстанавливаются
в том же браузере по тому же адресу страницы. Сохранение привязано к исходному
manifest; другой корпус не получает старые метки. Если браузер запрещает хранилище,
интерфейс сообщает об этом. JSON остаётся переносимой копией для передачи и продолжения.
Автосохранение не переносится между localhost и локальным HTML-файлом.

Чтобы продолжить из JSON, раскройте «Точные значения и дополнительные настройки»,
затем «Открыть другие файлы или продолжить сохранённую разметку». Выберите сохранённый
manifest; встроенные WAV останутся загруженными. Исходный `tools/vad-annotator.html`
без сборки требует выбрать manifest, WAV и при желании sources.json вручную.

Загрузка не меняет `unknown`/`heuristic` на подтверждённые статусы. Имеющиеся
`manual`/`verified_noise` сохраняются как утверждения импортированного manifest;
браузер не подтверждает их заново. Транскрипция — подсказка, не разметка.
Никакого автоматического определения речи нет.

Принимаются только локальные имена WAV без путей и URL, PCM16 mono 16000 Гц,
до 30 секунд. Частота проверяется по исходному WAV-заголовку. Браузер может
ресэмплировать декодированную волну: ось времени и номера сэмплов всё равно
используют исходную длину PCM и `time * 16000`, а не частоту AudioContext.
JSON ограничен 1 MiB, WAV — 1025536 байт. Аудио и JSON остаются в браузере;
страница не делает сетевых запросов.

Для итогового сравнения используйте экспорт с `--validated-only`. Этот режим
отклонит manifest, пока хотя бы один клип остаётся unknown/heuristic. Шесть
исходных noise-клипов не считаются проверенной тишиной без ручной проверки.

Обновлённый интерфейс проверен на 18 реальных WAV: 76 утверждений с DOM/audio-stub
(drag, добавление, пересечения, undo, неизменность подсказки, длительность preview,
отмена отложенного запуска, переход, экспорт и восстановление). В настоящем браузере
проверены перетаскивание, отмена, масштаб, воспроизведение участка и восстановление
состояния. Это проверки инструмента; ручная приёмка аудиокорпуса остаётся за слушателем.
