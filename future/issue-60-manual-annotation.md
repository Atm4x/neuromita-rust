# Ручная разметка VAD

Откройте `tools/vad-annotator.html` в современном браузере как локальный файл.
Сервер, сеть и установка зависимостей не нужны. Исходные файлы не перезаписываются.

1. Выберите `assets/eval/manifest.json` и все соответствующие WAV через поля файлов.
   При необходимости выберите `assets/eval/sources.json`: появится транскрипция.
2. Выберите клип, прослушайте его. Щелчок по волне перемещает проигрывание;
   под волной показаны миллисекунды и сэмпл исходного аудио.
3. Задавайте полуоткрытые интервалы `[начало, конец)` целыми сэмплами.
   Кнопки «Текущее → начало/конец» копируют позицию проигрывания в поля.
   Добавляйте, удаляйте и сортируйте интервалы. Для изменения интервала удалите
   прежний и добавьте исправленный. Пересечения и выход за длину запрещены.
4. После проверки всего клипа нажмите «Подтвердить ручную разметку» (`manual`).
   Для проверенного отсутствия речи удалите все интервалы и нажмите
   «Подтвердить отсутствие речи» (`verified_noise`). Любая правка интервалов
   сбрасывает статус в `unknown`; подтвердите заново после проверки.
5. Нажмите «Экспортировать полный manifest». Сохранится `manifest-manual.json`
   со всеми клипами, полями и статусами. Для экспорта нужны WAV всех клипов:
   программа повторно проверяет длины и интервалы. Перенос файла в корпус —
   отдельное осознанное действие пользователя. После перезагрузки страницы
   продолжайте с экспортированного manifest; автоматического сохранения нет.

Загрузка не меняет `unknown`/`heuristic` на подтверждённые статусы. Имеющиеся
`manual`/`verified_noise` сохраняются как утверждения импортированного manifest;
браузер не подтверждает их заново. Транскрипция — подсказка, не разметка.
Никакого автоматического определения речи нет.

Принимаются только локальные имена WAV без путей и URL, PCM16 mono 16000 Гц,
до 30 секунд. Частота проверяется по исходному WAV-заголовку. Браузер может
ресэмплировать декодированную волну: ось времени и номера сэмплов всё равно
используют исходную длину PCM и `time * 16000`, а не частоту AudioContext.
JSON ограничен 1 MiB, WAV — 1025536 байт. Аудио и JSON остаются в браузере;
страница не делает сетевых запросов.

Для итогового сравнения используйте экспорт с `--validated-only`. Этот режим
отклонит manifest, пока хотя бы один клип остаётся unknown/heuristic. Шесть
исходных noise-клипов не считаются проверенной тишиной без ручной проверки.
