# Единое приложение

Стандартная сборка: `cargo build --locked --offline -j 2`. Cargo создаёт один прикладной бинарник `neuromita` (Windows: `neuromita.exe`). GUI, MCP и SQLite входят в default features.

- Без аргументов — полное приложение с GUI.
- `--headless` — те же Core, провайдеры, GameLink, каталог промптов и сохранённые настройки без окна.
- `--data-dir ABSOLUTE_PATH` — явный каталог данных, совместим с `--headless`. По умолчанию используется `UserData` рядом с EXE.
- `--version` — единая версия приложения из Cargo.toml.
- `agent`, `agent-http`, `mcp-stdio`, `i18n`, `beat-sync`, `semantic-benchmark`, `telegram-voice-smoke` — прежние инструменты как подкоманды того же файла.

## MCP

Раздел «Настройки → MCP» сохраняет Core-owned `McpSettings` через SettingsPresenter/SettingsOwner. По умолчанию сервер выключен. Endpoint по умолчанию `http://127.0.0.1:8766/mcp`. Можно задать другой HTTP loopback IP, порт и путь. Разрешения изменения данных и чтения содержимого задаются отдельно.

При включении доступны Presenter-инструменты и диагностическое чтение Core/GameLink. Отдельный `--core-debug` нужен только прежнему stdio-мосту. Изменения по-прежнему требуют разрешения записи.

Включение, изменение адреса/разрешений и выключение применяются без перезапуска. Индикатор берётся из состояния реального слушателя; ошибка привязки сокета показывается рядом. Отключение закрывает слушатель и текущие MCP-соединения.

Streamable HTTP реализован официальным `rmcp`, поверх прежних typed IPC-команд к тому же Core. Второй Core или отдельный MCP-процесс не создаются. Browser Origin запрещён; наружные сетевые интерфейсы не принимаются. Персональные настройки и ключи не включаются в репозиторий.

## Обновление

Пакет содержит `neuromita.exe`. Для замены запущенного файла установщик создаёт частную копию **этого же приложения** в `.neuromita-updater/neuromita.exe` и запускает внутреннюю команду обновления. Это не отдельная сборка или второй пользовательский launcher. Сохраняются journal, проверка identity родителя, health receipt и rollback.

Издательское имя native release asset остаётся прежним (`neuromita-gui-windows-x86_64.exe`), чтобы не ломать протокол уже опубликованных релизов. В portable ZIP и при установке имя приложения — `neuromita.exe`.

## Layout & colors audit: MCP

Новая вкладка использует общий SettingsTabsStrip и SettingsSectionHeading. Содержимое — один VerticalLayout с выравниванием к началу, padding 2 px и spacing 12 px. URL занимает ширину контейнера; EditorField задаёт высоту 64 px, поле ввода 40 px. Состояние и ошибка не занимают область кнопки: ошибка переносится по словам и участвует в расчёте высоты. Абсолютные x/y не используются.

Используются общие компоненты StyledCheckbox, EditorField/SettingsField, SettingsLabel и SettingsButton. Поле: SettingsTheme.field `#090a16e0`, граница `#ffffff1f`, текст `#f3edf6`, подпись `#bca9bb`; ошибка `#ffb4b4`. Вкладка не вводит собственную палитру и отдельный scrollbar. Настройки и состояние слушателя приходят из Core; Slint хранит только текущий редактируемый ввод до нажатия «Применить».
