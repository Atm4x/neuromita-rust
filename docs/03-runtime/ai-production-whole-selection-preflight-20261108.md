# AI production whole-selection preflight (C3/C4, 2026-11-08)

`AiProductionInstaller::prepare` now resolves and preflights **all** selected TTS/ASR service plans before it publishes any backend, overlay or model asset. A later, unsupported service must not leave earlier services partially installed.

The preflight uses the actual managed Python SDK plan for every selected model. It checks Python/plan validity, executable build-stage support, backend and supplemental backend compatibility, pinned backend lock validity, explicit install-action approval, required model asset selection, installed revision verification and generation-hook approval. A caller-selected model source catalog is resolved once into concrete pinned sources for execution; the manifest is not loaded again during the publication phase. Sources from a local file are checked for regular-file/symlink safety, size and SHA-256 before the first backend is installed. HTTPS sources receive nonmutating URL validation, with actual content SHA-256 checked during staging.

`ModelAssetStore::planned_sources` is shared between preflight and publication: matching role/path and hash requirements have one interpretation. Preflight is deliberately not an integrity receipt; `publish` repeats its checks during transfer. Existing immutable asset receipts can still be reused without the original source file if the installed revision verifies.

Limits: managed Python/bootstrap/SDK preparation occurs **before** these checks and may write bootstrap files. The checks do **not** prove atomicity for later uv errors, interrupted downloads, disk exhaustion, worker activation, cross-process concurrent changes or malicious source mutation between preflight and transfer. Previously published independent layers remain immutable, and failed model selection still does not activate a worker. A durable whole-plan commit marker, recovery, atomic activation and rollback remain to be implemented separately.

Verification: Linux Rust 1.98.1 vendored offline; `cargo test --locked --offline --test ai_production_installer -- --test-threads=1` passed **15/15**, including six new late-service fail-before-publish checks. `cargo test --locked --offline --lib ai_runtime::assets::tests -- --test-threads=1` passed **2/2**. `cargo check --locked --offline --features gui --bin neuromita-gui` passed; this is a compile-time check, not evidence of a real Fish Speech/Triton inference path.
