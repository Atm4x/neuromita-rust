## Absolute-positioning acceptance

No direct `x` / `y` coordinates in **either new** `ui/pages/ai-hub.slint` or `ui/ai-hub/components.slint`. No negative margins, offsets or layout-magic to place labels, icons or controls. `HorizontalLayout` / `VerticalLayout` / `ScrollView` own all geometry. The settings subpage is a declarative conditional layout, **not** an absolutely positioned dialog painted over controls. The rounded settings icon gets its own 34×34 layout cell.

## Limits and deliberate non-parity

This is a **source-based** design audit, not visual screenshot verification of the PyQt window. No actual PyQt instance was started in this cycle. The demo fixture includes representative component names and illustrative values **not authoritative catalog records**, clearly marked `GUI preview · без runtime`. No install/uninstall/save, queue, dynamic schema renderer, validation, compile, readiness, localization, or presenter/IPC implementation. These user-visible features require separate acceptance and should not be reported complete. The page state is currently local to Slint so it can be exercised without any presenter; the navigation sidebar entry likewise toggles its own local visibility without changing the Rust navigation enum or presenter.
