# Slint first-run onboarding — lifecycle and remaining acceptance

The installed GUI loads the existing portable `settings.json` before starting its Rust desktop runtime. Missing settings or `onboarding.eula_accepted=false` display the blocking RU/EN EULA overlay. Reject closes the window without granting consent. Accept stores consent and the selected UI language, leaving unrelated settings intact, then opens the guide and starts the Rust runtime. Corrupted settings fail rather than being replaced with defaults.

The Guide has Basic (3), Advanced (5), and Full (13) pages, bundled screenshots, page contents/sections, image focus, zoom/crop/pan and local Wiki links. `onboarding.guide_level` and `onboarding.guide_page` are stored through the existing Settings Owner. First-run `guide_completed=false` makes a previously interrupted guide reopen at the last persisted page after restart. The final Finish action sends a completion command and only dismisses the guide after the Settings Owner confirms its durable flush. Ordinary Close temporarily dismisses without completing; Settings can reopen the guide. Existing already-accepted Rust settings that predate `guide_completed` are treated as complete to avoid an unexpected repeat wizard; accepting the EULA on an unaccepted profile resets progress to the first page.

The RU/EN EULA text came without edits from read-only Python reference `src/localization/eula_texts.py` at `5f3d061f523d9abefa6a264bb2953048a935fa65`; that historical compatibility reference does not constitute new legal approval. The GUI only supports accepting RU/EN; unsupported EULA locale selection is rejected. CLI/headless Rust runtime has no EULA startup gate.

Tests cover clean install and EULA persistence, offline restart, interrupted guide page restoration, completing without losing settings, old accepted profiles and invalid JSON. This is not yet native Windows keyboard-only/accessibility approval or a complete screenshot-based Python/PyQt visual parity check. Issue #41 remains open until those user-facing gates are verified.
