# Локальная проверка микрофона

`serve_microphone_check.py` обслуживает `microphone-check.html` на
`http://127.0.0.1:8768`. Используется стандартная библиотека Python.

```powershell
python tools/serve_microphone_check.py --probe C:/absolute/native_vad_probe.exe --ffmpeg C:/absolute/ffmpeg.exe --model C:/absolute/silero_vad.onnx --ort C:/absolute/onnxruntime.dll
```

`native_vad_probe` должен быть заранее собран с `--features vad-silero`.
DLL и модель проверяются самим Rust-провайдером. Сервер не устанавливает зависимости,
не собирает проект и не загружает модели. Пути задаются явно; личные device IDs
не входят в исходники.

1. Включить микрофон, разрешить доступ и выбрать нужное устройство.
2. Проверить уровень: кнопка записи доступна только после получения аудиокадров.
3. Нажать запись, говорить, остановить; ограничение — 30 секунд аудио.
4. Прослушать запись и при необходимости скачать WAV.
5. По желанию проверить тот же WAV через локальные Earshot и Silero при 0.5.
6. Выключить микрофон отдельной кнопкой. Закрытие страницы также останавливает треки.

Браузер запрашивает отключение noise suppression, echo cancellation и auto gain.
Фактические параметры отображаются на странице. Выбор входа — через браузерный
deviceId, без неявного перехода к другому входу при ошибке выбранного устройства.
Capture downmix выполняется в AudioWorklet, resampling — в OfflineAudioContext,
итог — mono PCM16 16 кГц. Прослушивание использует именно итоговый WAV.

До нажатия записи PCM не накапливается. Запись хранится в памяти вкладки;
скачивание — явное действие. Только кнопка анализа отправляет её локальному
серверу, который проверяет формат/размер, пишет во временный каталог `.cache/mic_*`,
запускает Rust для двух провайдеров и удаляет каталог при завершении. Сбой процесса
сервера или ОС может оставить временный каталог. Внешних API и ASR нет.

Сервер слушает только IPv4 loopback, проверяет Host/Origin каждого
запроса. Доступен один анализ одновременно, subprocess ограничен 50 секундами
на провайдер. Произвольные команды и пути от страницы не принимаются.

Это проверка браузерного захвата и offline Rust VAD на одном фрагменте.
Она не доказывает работу DirectShow, hotplug, GUI-контроллера или реального ASR.

Проверка реализации: синтаксис Python/JS; настоящий WAV `ru-01.wav` через HTTP
и оба Rust-провайдера — по одному сегменту и 119040 принятых сэмплов;
после запроса временный каталог удалён. Автоматизированная проверка браузерного
интерфейса не завершилась из-за таймаута browser tool. Позднее пользователь
самостоятельно записал и отправил речь: оба провайдера нашли по три сегмента,
см. [отчёт](../future/evidence/issue60-capture-20261104/user-microphone.md).
После исправления дополнения проверен WAV на 119041 сэмпл: 255 добавленных
нулевых сэмплов, оба провайдера успешно приняли 119296 сэмплов и нашли речь.
Пять регрессионных тестов проверяют сохранность PCM, формат, ошибки Rust и отклонение неполного анализа:
`python -m unittest discover -s tools -p test_microphone_check.py -v`.

Для анализа копия WAV дополняется нулевыми сэмплами до окна 512 (менее 32 мс).
Исходная запись в браузере не меняется. Отчёт содержит original_sample_count и
padding_samples. При ошибках сохраняются JSON summary, stderr и exit_code.
