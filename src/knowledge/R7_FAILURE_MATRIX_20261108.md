# R7 failure and provenance contract — Agent A Cycle44

**Acceptance status: OPEN.** R7 requires the full user-visible failure matrix, including missing/corrupt index, timeouts, partial sources, and model/provider failure. Passing this targeted provenance slice is not sufficient to mark R7 PARTIAL or PASS without the missing workflows.

## Canonical boundary

`MitaView` is the single owner of visible History. The retrieval result is a derived candidate, not a new authority. At final `render_history_evidence` / `render_archived_history_evidence` admission, the selected character, branch, Timeline prefix, archived `HistoryWindow`, original `EventId`, User/Assistant role, exact source metadata (`message_id`, `sequence`, `learned_at`, `role`, `branch_id`, `through`) and **exact Unicode character-budgeted content** are reconstructed from the current `MitaView`. The renderer also rejects Selected-vs-hit-count inconsistency, duplicate `EventId`, missing/duplicate/invalid retrieval methods and nonfinite scores. This avoids treating a valid prefix of a message as a verified complete quote or accepting metadata spoofing after fusion/reranking. A validation error is `HistoryEvidenceError::InvalidEvidence` or `StaleSelection`, not alternate retrieval.

`history_retrieval::hit` already owns the canonical metadata format; the renderer compares against it instead of introducing a second serialization contract. Legitimate search results truncated at the same `max_content_chars` budget remain valid. The renderer does not modify Timeline, change visibility, allocate a persistent index or perform model calls.

## Cycle45 — typed application-owned Python worker restart boundary

`RunningAiApplication` now retains the **exact resolved, immutable activation plan** for its own selected worker(s); its `AiRestartTicket` captures application ownership, service and observed worker generation. Restart is explicitly requested via `prepare_restart(service)` followed by `restart(ticket)`, never triggered implicitly by an embedding or reranker error. In split topology only the selected service is replaced; in shared topology the complete composed worker and all its selected services are reinitialized as a unit. The ticket cannot be used by another application instance or replayed after the generation changes.

Before preparing a candidate process, the supervisor validates under the same per-worker activation lock that the original generation **and the exact previously prepared model set** (`service`, `plugin_id`, `settings`, `asset_revision`) still match the pinned plan. A concurrent switch or separate model initialization invalidates the prepared-model marker; a later ticket fails with `StaleGeneration` or `ActivationSuperseded`. The new process is only published after every model reports readiness; a failed candidate leaves the original process and generation untouched, so the same ticket may retry. Runtime model asset revisions are rechecked by `WorkerProcess::launch` when configured, not silently bypassed. Generic `AiSupervisor::call("initialize", ...)` is rejected; the typed `initialize` operation invalidates the previous prepared-model marker under the activation lock.

For applications initialized through `activate_with_hardware`, the prepared plan alone does **not** carry the original persisted hardware store lease or verifier. An affected hardware-guarded worker is explicitly **not restartable** by this API; it must obtain a newly verified hardware selection via its real owner. No GUI button, automatic restart, persisted plan mutation or fallback to another plugin was introduced.

Focused integration evidence: `ai_application_restart` covers split-worker isolation, shared-worker atomic replacement, stale/replayed ticket rejection, refusal of a ticket from another running application and candidate initialization failure without replacing the old generation. This is the application/supervisor contract; a fully wired Desktop Presenter user action, model readiness/asset store mutation race under production installer, and end-user error/repair sequence are still **OPEN**. R7 remains formally OPEN.

## Unclosed required R7 work

1. **Documents R6** has no accepted owner/index/version/citation boundary, so corrupt/missing document-index, rebuild, partial document batch and recovery cannot be tested end to end. Do not emulate a persistent document index from ephemeral History FTS5.
2. **Timeouts, process crash and cancellation:** Cycle41 proves actual Python embedding and reranker subprocess `infer` timeouts through the **production adapters** to the Request API; Cycle43 additionally proves both actual worker process crashes mid-infer, with no LLM invocation, original failure preserved, split-worker isolation and successful same-application explicit restart/retry. Stock `AiKnowledgeSelection` embedding+reranker composition is proved separately. These tests use deterministic mock plugins (no real model inference), and the fault-injected run uses direct adapter injection instead of a live `AiKnowledgeSelection` supervisor reference. **Automatic restart from normal app/GUI, a user-operated worker restart action, production model timeout acceptance and a full end-user recovery sequence remain unverified**; no new timeout default has been introduced.
3. **Partial multi-source failures** require an explicit all-or-nothing/degraded-results policy accepted by the user. Do not invent lexical fallbacks when one semantic source fails.
4. **Cycle42 AI Engine status and existing Sandbox/terminal error text** are exposed through the current presenter/renderer. Cycle43 independently executes the actual AI Engine **component** on a headless Slint renderer. Cycle44 routes the full AppWindow fixture through the real `Update::RuntimeStatus` dispatcher and compares Failed/ModelReady pixels; full executable proof requires an external-memory runner, independently of the local `cargo check`. Full real-model GUI/CLI interaction, a user-triggered restart/retry from the Desktop Presenter, and corrupted derived-state recovery remain unproven.

The current implementation remains a strict, local, source-owned retrieval engine with **no parallel mutable Memory/History index**, no implicit mode change and no unrelated Legacy modifications.
