# Typed Timeline message content (agent B2)

Canonical Timeline events store ordered `content` parts as JSON, never embedded binary bytes. `TimelineMessagePart` accepts `text`, `image`, `audio`, `file` with a typed `TimelineAssetRef`; historical string content and `{ "text": ... }` parts remain readable. All other part shapes, extra fields, and contradictory MIME categories fail explicitly. No secondary history is created. A message's role, speaker and external identity are retained in its `VisibleMultimodalMessage`, which is derived only from a fixed `MitaView`.

`generation::multimodal` exposes pure codec boundaries, taking a caller-supplied `MitaView` and injected `TimelineAssetStore`. Gemini supports JPEG/PNG/WebP/GIF and WAV/MPEG/Ogg/FLAC as bounded `inlineData`; OpenAI Chat Completions and Responses support input images only. Unsupported media, assistant-side images for OpenAI, missing or corrupt files, and oversized requests fail closed. The total binary input cap is 16 MiB and per-part cap is 8 MiB. These are serialization limits, not a guarantee of model-specific quotas or server acceptance.

**Status / live integration:** The generation request now receives an optional injected `TimelineAssetStore`. Both Gemini `generateContent` and OpenAI Chat/Responses resolve binary parts strictly from the current `MitaView` and attach them to the corresponding EventId's historical message after provider transformations. Text-only world events, memory, working state, game state, reminders, current task, system policies and native tool history keep their existing locations. If message transformations merge, reorder, rewrite or ambiguously reproduce the media-bearing history, the provider request is rejected before network transmission; no fallback to text-only generation is permitted. Unsupported MIME, absent/modified bytes and missing configured store also fail closed. Observers receive a redacted media payload marker instead of base64 request contents, so diagnostic tracing does not retain user binary data. Only supported image/audio codecs are allowed; `file` is not silently converted. File ingress into Timeline remains a separate action, not an implicit generation trigger. Archive-aware GC is still pending; the app's global portable data root remains Agent D's responsibility.

Representative regression: `cargo test --locked --offline --test timeline_assets --test timeline_multimodal --test timeline_conversation --test timeline_mitaview --test openai_protocols`. Fixture coverage includes historical prefixes, fork/hide, cross-character visibility, media order and codec dialect, missing/tampered bytes, and explicit unsupported formats.
