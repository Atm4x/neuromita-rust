# Timeline append — локальная проверка сложности

Дата: 2026-11-01. Это **измерение** существующего workload, не норматив производительности или гарантия для SQLite/CFMD.

## Метод

- Rust 1.98.1, dev/debug profile, Linux, локальный CPU, offline dependencies.
- `cargo run --offline --example timeline_append_bench -- 1000 4000 8000`.
- Один `TimelineStore`, одна ветка, уникальный `UnityEvent` с пустым observer set на каждый append, уникальные ключи операции; `expected_head` увеличивается последовательно.
- Baseline: локальный `a72b1c1`, исходный валидатор с линейным просмотром всей истории при каждом append. Новый вариант: тёплый доменный индекс событий и знаний по BranchId.
- Контроль: конечный `head_sequence` равен числу событий. Указано время одного репрезентативного измерения каждого варианта; цифры имеют колебания и не отражают cold/reopen или SQL.

| Размер истории после append | Baseline, мс суммарно | С индексом, мс суммарно | Baseline, мкс/событие | С индексом, мкс/событие |
| ---: | ---: | ---: | ---: | ---: |
| 1 000 | 76.0 | 6.0 | 76.0 | 6.0 |
| 4 000 | 1 146.3 | 28.7 | 286.6 | 7.2 |
| 8 000 | 4 448.9 | 49.8 | 556.1 | 6.2 |

Для 8 000 событий это около 89× в данном debug workload. Выигрыш достигается **без второй доменной логики в SQLite**: `AppendIndex` обслуживает проверки batch поверх ранее подтверждённого `WorldIndex`. При сбое batch основной индекс и журнал не мутируют.

## Оставшаяся стоимость

- При **первом** append после cold reopen SQLite реконструирует родовую цепочку, затем индекс строится по всей истории. Это O(история) и остаётся незакрытым.
- `TimelineStore::world()` / `character_view()` формируют исторические проекции, не оптимизированы этим патчем.
- БД SQLite не превращена в чисто инкрементальный backend: измерения выше относятся к in-memory доменному append. Для SQLite и CFMD нужны отдельные измерения транзакций, хранилищных запросов и восстановления.
- Размер индекса увеличивается с числом виденных идентификаторов и известных событий; кешируемая проекция не заменяет источник истины.
